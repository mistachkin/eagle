# Eagle Scripting Language

Eagle (Extensible Adaptable Generalized Logic Engine) is an implementation
of the Tcl scripting language for the Common Language Runtime (CLR).  It is
written entirely in C# and provides most of the functionality of the Tcl 8.4
interpreter while incorporating selected features from Tcl 8.5 and Tcl 8.6,
in addition to adding entirely new features.
